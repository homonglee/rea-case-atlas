# REA Case Atlas

REA 사용이 명시된 공개 실행 보고 57건과 출처 링크 58개를 탐색하는 한국어 사이트입니다. 설명은 공백을 포함해 285~320자입니다. 공식 시연, 사용자 보고, 비교 실험, 영상 설명란을 구분합니다.

검색·분야 및 자료 유형 필터·페이지 이동·브라우저 내 사례 저장·상세 팝업·개별 사례 링크를 제공합니다. 외부 API와 방문자 계정은 필요하지 않습니다.

## 로컬 검사

Node.js 22 이상을 사용합니다. 의존성 설치는 필요하지 않습니다.

```bash
npm run build
npm run verify
```

원본 데이터는 `data/cases.json`이며 `npm run build`가 `dist/cases.js`를 생성합니다. `dist/`가 실제 배포 파일입니다. `npm run verify`는 데이터와 이벤트 처리 흐름을 검사하며 실제 브라우저의 레이아웃이나 포커스 동작을 대신 검증하지 않습니다.

## Vercel 배포 대상

- GitHub 저장소: [homonglee/rea-case-atlas](https://github.com/homonglee/rea-case-atlas)
- 운영 브랜치: `main`
- Vercel 프로젝트 예정 이름: `rea-case-atlas`
- 빌드: `npm run build`
- 결과 폴더: `dist`
- 연결할 주소: `https://rea.homong-app.com`

이 저장소는 Vercel 배포용 소스와 설정을 포함합니다. Vercel 프로덕션 배포와 DNS 연결의 완료 여부는 각 서비스에서 별도로 확인해야 합니다.

DNS는 Cloudflare에서 관리하며, Vercel이 해당 프로젝트와 도메인에 반환한 정확한 CNAME 및 필요한 소유 확인 값으로 설정합니다. 아직 반환되지 않은 DNS 대상을 임의로 정하지 않습니다.

## 수록 기준

조사 기준일은 2026년 10월 17일입니다. 100건은 수집 목표이며 실제 확인·수록된 건수와 구분합니다. 설치 안내, 실행 전 예시 프롬프트, 재게시, 다른 도구 소개는 집계에서 제외합니다. 같은 예제의 반복 보고는 통합합니다.

공개 원문에 기록된 수행 범위와 한계를 요약했으며, 모든 실험을 이 아카이브 제작자가 독립 재실행한 것은 아닙니다.
